# Week 1 – Cybersecurity Internship

## Overview

During Week 1 of my Cybersecurity Internship, I worked on setting up a basic cybersecurity lab environment using Oracle VirtualBox and Kali Linux.

The task focused on virtualization, Linux installation, network configuration, and troubleshooting internet connectivity.

## Tasks Completed

### 1. Oracle VirtualBox Installation

Installed and configured Oracle VirtualBox to create and manage a virtual machine for cybersecurity practice.

### 2. NAT Network Configuration

Configured the virtual machine networking using a NAT Network to provide network connectivity to the Kali Linux environment.

### 3. Kali Linux Installation and Setup

Installed Kali Linux inside Oracle VirtualBox and completed the initial system setup.

### 4. Network Configuration

Configured the required network parameters:

- IP Address
- Netmask
- Gateway
- DNS Server

### 5. Internet Connectivity Testing

Tested the network connection from Kali Linux and verified that internet connectivity was working successfully.

### 6. Troubleshooting

During the setup, I faced an internet connectivity issue. I checked the network configuration and troubleshooting steps and successfully resolved the issue.

## Key Learning

Through this task, I gained practical experience with:

- Virtualization
- Oracle VirtualBox
- Kali Linux
- IP addressing
- Network configuration
- DNS configuration
- NAT networking
- Basic network troubleshooting
